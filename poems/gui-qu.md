# 《归去》 · Homeward

[← README selection](../README.md) · [All poems](../more_poems.md)

Two rhyming poems · → ↓

```text
人 归 旧 柳 寒
去 鸟 枕 青 烟
旧 枕 重 帘 掩
柳 青 帘 外 晚
寒 烟 掩 晚 山
```

**Chinese rhyme:** 十一安 (an / ian / uan / üan).

## Across →

| 中文 | English |
| --- | --- |
| 人归旧柳寒， | Someone returns; the old willow is cold. |
| 去鸟枕青烟。 | A departing bird takes blue-green haze for a pillow. |
| 旧枕重帘掩， | Layered curtains veil the old pillow. |
| 柳青，帘外晚， | The willow is green; beyond the curtain, dusk. |
| 寒烟掩晚山。 | Cold haze veils the evening hills. |

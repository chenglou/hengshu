# 《绣愁》 · Embroidering Sorrow

[← README selection](../README.md) · [All poems](../more_poems.md)

Two rhyming poems · → ↓

```text
相 对 方 念 旧
看 图 识 旧 友
故 问 愁 谁 有
人 老 难 如 旧
瘦 手 绣 旧 愁
```

**Chinese rhyme:** 十欧 (ou / iou).

## Across →

| 中文 | English |
| --- | --- |
| 相对方念旧， | Face to face, only then do I recall old times. |
| 看图识旧友。 | I recognize an old friend in the image. |
| 故问：愁谁有？ | So I ask: who carries sorrow? |
| 人老难如旧， | With age, it is hard to be as before; |
| 瘦手绣旧愁。 | A thin hand embroiders old sorrow. |
